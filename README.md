# راهنماهای فشردهٔ فارسی — هرمس ایجنت ۲.۰ + Node.js Design Patterns

نسخه‌های کوتاه، پرچگالی و تعاملیِ خلاصهٔ دو کتاب — مناسب یک نشست مطالعه (~۱۲ دقیقه هر کدام):

- **هرمس ایجنت ۲.۰ (نسخهٔ فشرده)** — ایجنت چیست، حلقهٔ خودبهبودی، حافظهٔ سه‌لایه، ابزارها و MCP، کانبان چندایجنته، امنیت + خودآزمایی تعاملی.
- **الگوهای طراحی Node.js (نسخهٔ فشرده)** — Event Loop، ماژول‌ها، async/await، استریم‌ها، جدول «مسئله ← الگو»، مقیاس‌پذیری، پیام‌رسانی + خودآزمایی تعاملی.

نسخه‌های کامل و عمیق‌تر هم در پوشهٔ [`full/`](full/) موجودند.

## ویژگی‌ها
- تک‌فایل مستقل (فونت وزیرمتن داخل فایل — آفلاین هم کامل رندر می‌شود)
- تم روشن/تاریب با ذخیرهٔ انتخاب (کلید `D`)، فهرست کشویی (کلید `T`)
- خودآزمایی تعاملی با پاسخ‌های بازشو (active recall)
- RTL، واکنش‌گرا برای موبایل
